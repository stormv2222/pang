# 메인 화면 구성

## 화면 레이아웃

게임 시작 시 가장 먼저 표시되는 화면으로, 다음 요소로 구성된다.

- **게임 타이틀**: "PANG" 로고 중앙 표시
- **게임 시작 버튼**: 클릭 시 게임 화면으로 전환
- **게임 종료 버튼**: 클릭 시 종료 확인 다이얼로그 표시
- **배경**: 밝은 여름 하늘 그라데이션

## 진입 흐름

```
메인 화면
  ├── 게임 시작 → 게임 화면으로 전환
  └── 게임 종료 → confirm 다이얼로그 → 탭 닫기
```

## UI 요소

| 요소 | 위치 | 설명 |
|------|------|------|
| 타이틀 | 중앙 상단 | "PANG" 텍스트, 햇살 그라데이션 효과 |
| 게임 시작 버튼 | 중앙 | 게임 화면 진입 |
| 게임 종료 버튼 | 중앙 (시작 버튼 하단) | 종료 확인 후 탭 닫기 |

## 비주얼 스타일

### 배경
- 여름 하늘을 연상시키는 수직 그라데이션
- 상단(진한 파란색 `#1565C0`) → 중간(하늘색 `#42A5F5`) → 하단(밝은 흰 하늘 `#E3F2FD`)
- 하늘 위에 흰 구름을 배치하여 여름 분위기 강조
- 구름은 CSS로 표현하며 배경에 자연스럽게 어우러지도록 한다

### PANG 타이틀
- 햇살 느낌의 그라데이션 텍스트
- 흰색 → 노란색(`#FFE566`) → 주황색(`#FFB347`) → 진한 주황(`#FF6B35`)
- 주황빛 발광 효과(`drop-shadow`) 적용

### 버튼
- 반투명 유리 느낌 배경 (`rgba(255,255,255, 0.15)`)
- 흰색 테두리
- 호버 시 배경이 밝아지는 효과

## 조작

| 입력 | 동작 |
|------|------|
| 마우스 클릭 | 버튼 활성화 |
| ↑ / ↓ 방향키 | 메뉴 포커스 이동 (게임 시작 ↔ 게임 종료) |
| Enter | 포커스된 버튼 실행 |
