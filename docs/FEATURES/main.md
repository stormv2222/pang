# 메인 화면 구성

## 화면 레이아웃

게임 시작 시 가장 먼저 표시되는 화면으로, 다음 요소로 구성된다.

- **게임 타이틀**: "PANG" 로고 중앙 상단 표시
- **시작 버튼**: START 버튼 (클릭 또는 키 입력으로 게임 진입)
- **배경**: 정적 배경 이미지 또는 단색 배경

## 진입 흐름

```
메인 화면
  └── START 선택 → Mission 1 스테이지 1 시작
```

## UI 요소

| 요소 | 위치 | 설명 |
|------|------|------|
| 타이틀 | 중앙 상단 | "PANG" 텍스트 |
| START 버튼 | 중앙 | 게임 시작 진입점 |

## 조작

- **마우스 클릭** 또는 **Enter 키**: START 버튼 활성화
