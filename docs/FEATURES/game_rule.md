# 게임 룰

## 기본 목표

화면에 등장하는 모든 공(버블)을 제한 시간 내에 와이어로 제거한다.

---

## 플레이어

- **이동**: 좌/우 수평 이동만 가능
- **공격**: 와이어(Harpoon)를 수직 위 방향으로 발사
- **와이어 동작**: 발사 후 천장 또는 공에 닿을 때까지 수직으로 고정 유지
- **사망 조건**: 공에 접촉하면 즉사

---

## 공(버블) 시스템

공은 화면 내에서 포물선을 그리며 바운스하고, 와이어에 맞으면 두 개로 분열한다.

| 크기 | 와이어 피격 결과 |
|------|----------------|
| 대(Large) | 중(Medium) × 2 생성 |
| 중(Medium) | 소(Small) × 2 생성 |
| 소(Small) | 제거 (점수 획득) |

- 공은 벽과 바닥에서 반사되며 이동
- 분열된 공은 더 빠른 속도로 이동

---

## 블럭

- 블럭은 부서지지 않는다
- 플레이어보다 높은 위치에만 생성된다
- 공(버블)은 블럭 위로 튕길 수 있다
- 공의 바운드 범위 내에서만 생성된다

---

## 제한 시간

- 각 스테이지에는 제한 시간이 존재한다
- 제한 시간 초과 시 게임오버

---

## 점수 체계

| 조건 | 점수 |
|------|------|
| 소(Small) 제거 | 기본 점수 |
| 중(Medium) 제거 | 기본 점수 × 2 |
| 대(Large) 제거 | 기본 점수 × 4 |
| 콤보 (연속 제거) | 보너스 점수 추가 |
| 스테이지 클리어 | 잔여 시간 × 보너스 |

---

## 스테이지 클리어 조건

- 화면 내 모든 공을 제거하면 다음 스테이지로 진행

## 게임오버 조건

- 공에 접촉하여 사망
- 제한 시간 초과
