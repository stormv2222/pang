# Phase 1 설계 - 메인 화면

## 목표

브라우저에서 게임을 실행하면 메인 화면이 표시되고,  
게임 시작 / 게임 종료 버튼이 마우스 클릭 및 키보드로 동작한다.

---

## 화면 구성 (레이아웃)

```
┌─────────────────────────────┐
│                             │
│                             │
│           PANG              │  ← 햇살 그라데이션 타이틀
│                             │
│        [ 게임 시작 ]         │  ← 시작 버튼
│        [ 게임 종료 ]         │  ← 종료 버튼
│                             │
│                             │
└─────────────────────────────┘
```

- 타이틀과 버튼은 수직 중앙 정렬
- 고정 캔버스 사이즈: **640 × 480px**

---

## 비주얼 스타일

### 배경
- 여름 하늘을 연상시키는 수직 그라데이션
- 상단(진한 파란색 `#1565C0`) → 중간(하늘색 `#42A5F5`) → 하단(밝은 흰 하늘 `#E3F2FD`)
- 하늘 위에 흰 구름을 배치하여 여름 분위기 강조
- 구름은 CSS로 표현하며 배경에 자연스럽게 어우러지도록 한다

### PANG 타이틀
- 햇살 느낌의 그라데이션 텍스트
- 흰색 → 노란색(`#FFE566`) → 주황색(`#FFB347`) → 진한 주황(`#FF6B35`)
- 주황빛 발광 효과(`drop-shadow`) 적용

### 버튼
- 반투명 유리 느낌 배경 (`rgba(255,255,255, 0.15)`)
- 흰색 테두리
- 호버 시 배경이 밝아지는 효과
- 키보드 포커스 시 시각적으로 구분되는 스타일 적용

---

## 화면 전환 구조

화면은 `App.tsx`에서 `currentScreen` 상태로 관리한다.  
Phase 1에서는 `'main'` 상태만 구현하며, `'game'`은 빈 화면으로 대체한다.

```
'main'  ──[게임 시작]──▶  'game'  (Phase 2에서 구현)
  ▲                           │
  └───────────────────────────┘ (Phase 13에서 연결)
```

---

## 컴포넌트 구조

```
App.tsx
  └── MainScreen.tsx       ← 메인 화면 전체
        ├── 구름 요소 (CSS로 표현)
        ├── 타이틀 텍스트
        ├── 시작 버튼
        └── 종료 버튼
```

### App.tsx 역할
- `currentScreen` 상태 보유 (`'main' | 'game'`)
- 상태에 따라 `<MainScreen />` 또는 빈 게임 화면 렌더링

### MainScreen.tsx 역할
- 타이틀, 버튼 렌더링
- `focusedIndex` 상태로 현재 포커스된 버튼 인덱스 관리 (0: 게임 시작, 1: 게임 종료)
- 버튼 클릭 이벤트를 props로 상위(`App.tsx`)에 전달
- 키보드 이벤트 처리 (`keydown` 리스너)

## 조작

| 입력 | 동작 |
|------|------|
| 마우스 클릭 | 버튼 활성화 |
| ↑ / ↓ 방향키 | 메뉴 포커스 이동 (게임 시작 ↔ 게임 종료) |
| Enter | 포커스된 버튼 실행 |

### 키보드 이벤트 처리 흐름

```
keydown 이벤트
  ├── ArrowDown → focusedIndex를 1로 변경 (게임 종료로 이동)
  ├── ArrowUp   → focusedIndex를 0으로 변경 (게임 시작으로 이동)
  └── Enter     → focusedIndex에 해당하는 버튼 동작 실행
```

---

## 버튼 동작

| 버튼 | 동작 |
|------|------|
| 게임 시작 | `currentScreen`을 `'game'`으로 변경 → 빈 게임 화면으로 전환 |
| 게임 종료 | 브라우저 confirm 다이얼로그 표시 → 확인 시 탭 닫기 시도 (`window.close()`) |

> `window.close()`는 브라우저 보안 정책상 직접 열린 탭에서는 동작하지 않을 수 있다.  
> 이 경우 "브라우저 탭을 직접 닫아주세요" 안내 문구를 표시한다.
