# Phase 3 설계 - 플레이어 이동

## 목표

게임 화면에 사람 모양의 플레이어 캐릭터가 등장하고,  
키보드 방향키(←→)로 좌우 이동하며 걷는 애니메이션이 표시된다.  
화면 경계를 벗어나지 않는다.

---

## 플레이어 스펙

| 항목 | 값 |
|------|-----|
| 크기 | 너비 30px, 높이 48px (머리 포함) |
| 초기 위치 | 캔버스 수평 중앙 (x: 320) |
| 바닥 기준 | FLOOR_Y (440px) — 플레이어 발이 바닥에 닿음 |
| 이동 속도 | 4px / 프레임 |
| 이동 방향 | 좌/우 수평만 가능 |
| 표현 방식 | Canvas 2D 드로잉 (원 + 선)으로 사람 형태 표현 |

---

## 캐릭터 드로잉 구성

Canvas 2D API로 사람 형태를 직접 그린다.

```
    ○        ← 머리 (arc)
    │        ← 몸통 (line)
   /│\       ← 팔 (line, 좌우)
  / │ \
 /  │  \
    │        
   / \       ← 다리 (line, 좌우)
  /   \
```

| 부위 | 드로잉 방법 |
|------|------------|
| 머리 | `arc()` — 원 |
| 몸통 | `moveTo / lineTo` — 수직선 |
| 팔 | `moveTo / lineTo` — 좌우 대각선 |
| 다리 | `moveTo / lineTo` — 좌우 대각선 |

- 색상: 단색 (`#E74C3C` 몸통, `#F5CBA7` 머리)
- `lineWidth`: 3px

---

## 걷기 애니메이션

이동 중일 때 프레임 카운터를 기반으로 다리/팔의 각도를 교대로 변경한다.

### 애니메이션 상태

| 상태 | 조건 | 동작 |
|------|------|------|
| 정지 | 키 미입력 | 다리/팔 기본 자세 |
| 걷기 | 방향키 입력 중 | 다리/팔 각도 교대 (2프레임 사이클) |

### 프레임 사이클

```
walkFrame 카운터 (매 프레임 이동 시 +1)

walkFrame % 20 < 10  → 자세 A: 왼다리 앞, 오른다리 뒤
walkFrame % 20 >= 10 → 자세 B: 오른다리 앞, 왼다리 뒤
```

- 팔은 다리와 반대 방향으로 움직임 (자연스러운 걸음)
- 다리 각도 오프셋: ±12px

## 경계 처리

```
좌측 경계: player.x >= 15   (너비 절반)
우측 경계: player.x <= 625  (640 - 너비 절반)
```

---

## 상태 관리

```ts
const playerRef = useRef({
  x: 320,
  walkFrame: 0,
})
const pressedKeysRef = useRef(new Set<string>())
```

- `walkFrame`: 이동 중에만 증가, 정지 시 0으로 리셋

---

## 입력 처리

```
keydown → pressedKeys Set에 키 추가
keyup   → pressedKeys Set에서 키 제거

게임 루프 (매 프레임)
  ├── ArrowLeft  → x -= speed, walkFrame++
  ├── ArrowRight → x += speed, walkFrame++
  ├── 이동 없음  → walkFrame = 0
  └── 경계 클램프 적용
```

## 렌더링 순서

```
draw()
  ├── 배경 렌더링 (Phase 2)
  └── 플레이어 렌더링
        ├── walkFrame 기반 자세 계산
        ├── 다리 그리기 (자세 A/B)
        ├── 몸통 그리기
        ├── 팔 그리기 (자세 A/B, 다리 반대)
        └── 머리 그리기
```
