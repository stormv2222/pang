# Phase 4 설계 - 와이어 발사

## 목표

스페이스바를 누르면 플레이어 위쪽으로 와이어가 발사되고,  
천장에 닿으면 사라진다. 와이어는 동시에 1발만 존재할 수 있다.

---

## 와이어 동작 규칙

1. 스페이스바를 누르면 플레이어 x 위치에서 위로 발사
2. 와이어 끝(tip)이 매 프레임 위로 이동하며 선이 위로 뻗어나감
3. tip이 천장(y=0)에 닿으면 와이어 제거
4. 와이어가 화면에 존재하는 동안 추가 발사 불가 (1발 제한)
5. **와이어가 활성화된 동안 플레이어 좌우 이동 불가**

---

## 와이어 스펙

| 항목 | 값 |
|------|-----|
| 발사 키 | Space |
| 발사 위치 x | 발사 시점의 플레이어 x |
| 발사 위치 y (시작) | 플레이어 어깨 위치 (`SHOULDER_Y`) |
| 이동 방향 | 수직 위 (y 감소) |
| 이동 속도 | 8px / 프레임 |
| 제거 조건 | tip이 y=0 (천장) 도달 시 |
| 동시 발사 제한 | 1발 |
| 색상 | `#FFD700` (금색) |
| 굵기 | 2px |

---

## 좌표 기준

```
y=0  ─────────────── 천장 (tip 도달 시 제거)
      │  ← tip (매 프레임 위로 이동)
      │
      │  ← 와이어 선
      │
      │  ← base (플레이어 어깨, 고정)
SHOULDER_Y
```

- 와이어 base(하단): 발사 순간의 `SHOULDER_Y` 고정
- 와이어 tip(상단): 매 프레임 `tipY -= 8`

---

## 플레이어 이동 제한

```
wire가 null     → 좌우 이동 가능
wire가 활성화   → 좌우 이동 불가 (키 입력 무시)
```

---

## 발사 모션 (Shooting Pose)

와이어가 활성화된 동안 플레이어는 발사 자세를 취한다.

### 발사 자세 특징
- 양팔을 위로 들어 머리 위에서 모으는 형태
- 다리는 정지 자세 유지 (걷기 애니메이션 없음)

```
    ○         ← 머리
   \│/        ← 팔을 위로 올린 형태
    │          ← 몸통
   / \         ← 다리 (정지)
```

### 발사 자세 좌표

| 부위 | 좌표 |
|------|------|
| 왼팔 끝 | `(x - 6, HEAD_CENTER_Y - 4)` — 머리 위 왼쪽 |
| 오른팔 끝 | `(x + 6, HEAD_CENTER_Y - 4)` — 머리 위 오른쪽 |
| 다리 | 정지 자세 동일 (`x±6, FLOOR_Y`) |

---

## 상태 관리

```ts
const wireRef = useRef<{ x: number; tipY: number } | null>(null)
```

| 상태 | 설명 |
|------|------|
| `null` | 와이어 없음 (발사 가능, 이동 가능) |
| 값 존재 | 와이어 이동 중 (발사 불가, 이동 불가, 발사 자세 유지) |

---

## 입력 처리

```
keydown 'Space'
  └── wireRef.current === null 인 경우에만
        → wireRef.current = { x: player.x, tipY: SHOULDER_Y }

방향키 이동
  └── wireRef.current === null 인 경우에만 이동 처리
```

---

## 게임 루프 흐름

```
draw() 매 프레임
  ├── 플레이어 이동 (wire === null 일 때만)
  ├── 와이어 업데이트
  │     ├── wire.tipY -= 8
  │     └── wire.tipY <= 0 → wireRef.current = null
  ├── 배경 렌더링
  ├── 와이어 렌더링 (wire !== null)
  └── 플레이어 렌더링
        └── wire !== null → 발사 자세
            wire === null → 기본/걷기 자세
```

---

## 렌더링

와이어는 선(줄)과 tip의 화살촉으로 구성된다.

```
    ▲   ← 화살촉 (삼각형, tip 위치)
    │
    │   ← 와이어 선
    │
```

### 와이어 선
- 색상: `#FFD700` (금색), 굵기 2px
- `(wire.x, SHOULDER_Y)` → `(wire.x, wire.tipY)` 수직선

### 화살촉 (삼각형)
- tip(`wire.tipY`) 위치에 위를 향하는 삼각형으로 표현
- 색상: `#FFD700` (와이어와 동일)
- 너비: 8px, 높이: 10px

```ts
ctx.fillStyle = '#FFD700'
ctx.beginPath()
ctx.moveTo(wire.x,     wire.tipY - 10)  // 꼭짓점 (위)
ctx.lineTo(wire.x - 4, wire.tipY)       // 왼쪽 하단
ctx.lineTo(wire.x + 4, wire.tipY)       // 오른쪽 하단
ctx.closePath()
ctx.fill()
```
