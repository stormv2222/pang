# Phase 2 설계 - 게임 캔버스 및 배경

## 목표

게임 시작 버튼을 누르면 게임 화면으로 전환되고,  
고정 크기의 캔버스에 만리장성 배경과 경계가 표시된다.

---

## 화면 구성 (레이아웃)

```
┌────────────────────────────────┐  ← 천장 경계
│                                │
│        [하늘 배경]              │
│                                │  ← 게임 플레이 영역
│                                │
│  [성벽]              [성벽]    │
├────────────────────────────────┤  ← 바닥 경계
```

- 캔버스 고정 사이즈: **640 × 480px**
- 하늘 영역: 상단 ~ 바닥 경계 직전
- 바닥: 게임 플레이 영역과 구분되는 색상의 띠
- 좌/우 벽: 캔버스 경계 자체가 벽 역할

---

## 비주얼 스타일

### 하늘 배경
- 수직 선형 그라데이션 (`createLinearGradient` 사용)
- 상단(짙은 하늘 `#4A90D9`) → 중간(밝은 하늘 `#87CEEB`) → 하단(지평선 `#D4EDFF`)

### 바닥
- 만리장성 돌 느낌의 짙은 회색/갈색 띠
- 높이: 약 40px
- 색상 예: `#8B7355`

### 경계선
- 바닥 상단에 명확한 구분선 표시
- 색상 예: `#5C4A2A`

---

## 기술 구조

### 렌더링 방식
- HTML `<canvas>` 엘리먼트 사용
- `useRef`로 canvas 참조, `getContext('2d')`로 렌더링
- `requestAnimationFrame` 기반 게임 루프 구성 (Phase 3 이후 게임 오브젝트 추가 대비)

### 게임 루프 구조
```
useEffect 마운트 시
  └── requestAnimationFrame 루프 시작
        └── draw() 호출
              └── 배경 렌더링 (하늘, 바닥, 경계)
```

### 좌표 기준

```
(0, 0) ─────────────────── (640, 0)   ← 천장
  │                              │
  │       플레이 영역              │
  │                              │
(0, 440) ────────────────── (640, 440) ← 바닥 시작
(0, 480) ────────────────── (640, 480) ← 캔버스 하단
```

- 바닥 y 기준: `440px` (바닥 띠 높이 40px)
- 플레이 가능 영역: y `0` ~ `440`

## 컴포넌트 구조

```
App.tsx
  ├── MainScreen.tsx    (Phase 1 완성)
  └── GameScreen.tsx    ← 신규
        └── <canvas>
```

### App.tsx 변경
- `currentScreen === 'game'`일 때 기존 placeholder 대신 `<GameScreen />` 렌더링

### GameScreen.tsx 역할
- canvas ref 보유 및 게임 루프 관리
- `draw()` 함수에서 배경 렌더링 담당
